# CR-001 — Native mobile app this semester

Source: proposed scope review of the existing native Android/iOS exclusions; no stakeholder request claimed. Draft recorded 2026-11-15. Decider: Liam Pheng (signature and decision date pending).

- **Cost:** rough estimate 40–60 hours for one platform, including login, core screens and device tests; both platforms would cost more.
- **Blast radius:** new client, API contract, authentication, mobile builds, release process and device testing.
- **Risk both ways:** accepting would displace authorization and verification work; declining leaves app-store delivery and offline behavior unavailable, while users can still access the web demo.

**Proposed disposition: REJECT for this semester.** Destination: existing native Android/iOS exclusions in requirements §7. Reopen only with dedicated staffing and a mobile acceptance plan. Liam Pheng to revise and approve or replace this draft.
